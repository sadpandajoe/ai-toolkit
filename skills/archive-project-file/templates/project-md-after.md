# PROJECT.md "Previous Work" Breadcrumb Template

After archiving, replace the archived sections in PROJECT.md with this breadcrumb. Keep PROJECT.md focused on what's active *now*; readers can dive into PROJECT_ARCHIVE.md for the full record.

```markdown
## Previous Work

### [Phase Name] — Completed [YYYY-MM-DD]
[1–3 sentence summary of outcome]
See PROJECT_ARCHIVE.md.

---

## Current Status
[Continue with active work]
```

## Rules

- "Previous Work" sits above "Current Status", so the reader sees recent context first and active work next.
